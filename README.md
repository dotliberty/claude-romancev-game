# Последнее свидание

Самостоятельная пародийная игра: свидание с Claude-тян, добрые и грубые ответы, ночная погоня и превращение персонажей в Руну и Сергея Романцева. Сцены и действия вымышлены и не являются утверждениями о реальных людях.

## Запуск

Нужен Node.js 22 или новее.

```sh
npm install
npm start
```

## Управление и проверка

Ответы выбираются мышью. В погоне — WASD или стрелки; пробел или левый Shift — рывок с восстанавливаемым запасом. M переключает звук. Escape возвращает к началу.

Реплики создаются онлайн: герой — `codex exec`, партнёр — `claude --print`. Требуются установленные CLI в PATH и выполненный вход в каждый из них. Можно задать пути через переменные `CODEX_CLI_PATH` и `CLAUDE_CLI_PATH`. Используются текущие учётные записи и их лимиты. Интернет нужен для генерации. Игрок выбирает намерение «Угодить» или «Оскорбить»; конкретные реплики пишут модели. Партнёр сам определяет обиду и возможность погони. Передаются только роли и история текущего свидания. Ожидание ограничено 120 секундами на реплику, ошибки показываются с возможностью повторить ход. Окна терминалов не открываются.

`src/dialogue.ts` управляет CLI и проверкой структурированных ответов; `src/preload.ts` предоставляет интерфейсу ограниченный мост IPC. Процессы работают без оболочки, Claude — без инструментов и пользовательских расширений, Codex — в режиме read-only без загрузки документов проекта. Закрытие приложения останавливает активный процесс.

Три добрых ответа завершают свидание. Любая грубая реплика начинает погоню. При первом опасном сближении герои превращаются; после 24 секунд открывается выход сверху. Доберитесь до него, избегая преследователя и препятствий. Поимка завершает попытку.

`npm run check` проверяет типы, `npm run build` компилирует TypeScript. После сборки `npx electron verify.cjs` проверяет порядок запросов и передачу истории, вывод реплик, добрый финал, обиду, погоню, превращение, выход и повтор при ошибке с подставным мостом CLI. Ручная проверка настоящего соединения: выбрать оба намерения, дождаться реплик каждого CLI, проверить погоню после обиды.

## Структура

- `src/main.ts` — окно Electron; размер 1200 × 1200 физических пикселей с учётом масштаба основного экрана.
- `src/game.ts` — состояния, диалоги, ввод, столкновения и погоня.
- `src/art.ts` — рисование сцен и персонажей.
- `src/audio.ts` — синтез музыки и звуков.
- `index.html` — поверхность игры, кнопки и собственная верхняя полоса.

Иллюстрации рисуются программно, музыка синтезируется локально.
